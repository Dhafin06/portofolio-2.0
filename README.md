# Portofolio 2.0

Personal portfolio built with React, Vite, React Router, Tailwind CSS, and Motion.

## Structure

```text
public/
  images/
  icons/

src/
  components/
  pages/
    Home.jsx
    About.jsx
    Projects.jsx
    Contact.jsx
  App.jsx
  main.jsx
  index.css

index.html
vite.config.js
jsconfig.json
package.json
```

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
